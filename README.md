# BSS campaign landing page — temporary review mirror

Static, read-only mirror of a **preview** page, published only so it can be reviewed in a browser.

- The form is in preview mode: it validates and shows the confirmation state locally. It makes **no** network
  request, creates no registration, writes to no database and sends no e-mail.
- `noindex, nofollow` in the page and `Disallow: /` in robots.txt. Not linked from brazilskanogometnaskola.hr
  and not in any sitemap.
- Contains only the rendered page, the logo (embedded) and the campaign video. No source, no configuration,
  no keys, no backend.

Delete this repository once the campaign page has been reviewed.
